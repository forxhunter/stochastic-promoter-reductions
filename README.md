# Benchmarking reductions of stochastic promoter models: code and data

Code and result tables for the manuscript "Benchmarking Reductions of Stochastic
Promoter Models: Noise Partition, Promoter Noise Strength and Switching"
(Tianyu Wu, University of Illinois at Urbana-Champaign).

## Contents

- `benchmarking/suite/` - simulation engine (SSA, hybrid/PDMP with Runge-Kutta and
  exact-flow samplers, sQSSA, averaged ODE), model definitions (`systems2.py`),
  finite-state projection and exact stationary solvers (`fsp.py`,
  `pdmp_stationary.py`, `pdmp_closed_form.py`), exact toggle escape rates
  (`toggle_exact.py`), the first-order theory (`qss_diffusion.py`,
  `first_order_coefficient.py`, `promoter_family*.py`), and the scripts that write
  every table and figure of the paper and its supplement (`make_*.py`,
  `plot_grid2.py`).
- `benchmarking/hill_vs_rational.py` - Hill fits to multisite occupancy curves
  (Supplementary Section S7).
- `benchmarking_results/` - the result tables (CSV) from which the figures and
  tables are generated.

Raw simulation trajectories are not included; they are regenerated by
`benchmarking/suite/run_grid2.py` and `benchmarking/suite/toggle_switching.py`,
which use deterministic seeds.

## Requirements

Python 3.13 with numpy 2.4, scipy 1.17, pandas 2.3, numba 0.67 and matplotlib 3.10
(the versions used for the paper; nearby versions should work).

## Reproducing

Run scripts from `benchmarking/suite/`. Each script states in its docstring which
file in `benchmarking_results/` it writes. The table scripts write LaTeX files into
`../../Supplementary_Material_v2_next_revision/generated/` and
`../../ElsiverFSPromoter_v2_next_revision/generated/`; create these directories, or
change the output paths at the top of each script.
