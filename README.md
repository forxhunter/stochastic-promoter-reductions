# Benchmarking reductions of stochastic promoter models: code and data

Code and result tables for the manuscript "Promoter response and noise strength in
reduced stochastic gene regulatory models" (Tianyu Wu, University of Illinois at
Urbana-Champaign; submitted to the Journal of Theoretical Biology).

## Versions

- `v1.0`: the version used for the submitted manuscript.
- `v1.1`: the version used for the revised manuscript. It adds the analyses requested
  in the first round of review (scripts `benchmarking/suite/revision_*.py` and
  `make_revision_tables.py`, results in `benchmarking_results/revision/`). The code
  and result files of v1.0 are unchanged.
- `v1.2`: adds the checks made after an internal second review of the revision: the
  architecture scan of the first-order coefficient (`revision_c1_scan.py`,
  `c1_scan.csv`), convergence checks of the metastable toggle rates
  (`revision_toggle_checks.py spectral_check`, `toggle_spectral_check.csv`), and label
  changes in the figure and table scripts. Results of v1.1 are unchanged.
- `v1.3`: fixes `make_revision_tables.py`, which read `toggle_spectral_check.csv`
  together with the spectral results and added empty rows to the table of
  metastable rates; caption wording of two tables. The exact metastable rates in
  Table 4 of the manuscript are the values `k_U_met` of `toggle_spectral_*.csv`.
  No result changes.

## Contents

- `benchmarking/suite/` - simulation engine (SSA, hybrid/PDMP with Runge-Kutta and
  exact-flow samplers, sQSSA, averaged ODE), model definitions (`systems2.py`),
  finite-state projection and exact stationary solvers (`fsp.py`,
  `pdmp_stationary.py`, `pdmp_closed_form.py`), exact toggle escape rates
  (`toggle_exact.py`), the first-order theory (`qss_diffusion.py`,
  `first_order_coefficient.py`, `promoter_family*.py`), and the scripts that write
  every table and figure of the paper and its supplement (`make_*.py`,
  `plot_grid2.py`).
- `benchmarking/hill_vs_rational.py` - Hill fits to multisite occupancy curves
  (Supplementary Section S7).
- `benchmarking_results/` - the result tables (CSV) from which the figures and
  tables are generated.
- Revision analyses (v1.1), each writing into `benchmarking_results/revision/`:

  | Script | Analysis | Output |
  |---|---|---|
  | `revision_reduction.py profiles` | residual drift and promoter autocorrelation profiles | `residual_profiles.csv`, `promoter_acf.csv` |
  | `revision_reduction.py identity` | numerical check of the multilevel drift identity | `identity_check.csv` |
  | `revision_reduction.py origin` | limit of the control F relaxation rate at zero regulator, and sensitivity | `lamF_origin.csv` |
  | `revision_reduction.py exact` | exact comparisons for the residual-drift example, local controls and system size | `reduction_exact.csv` |
  | `revision_toggle_checks.py truncation ...` | truncation convergence of the exact toggle rates | `toggle_truncation_*.csv` |
  | `revision_toggle_checks.py spectral ...` | metastable toggle rates from the spectral gap | `toggle_spectral_*.csv` |
  | `revision_boundary_exponent.py` | boundary exponent of the hybrid density for multistate promoters | `boundary_exponent.csv` |
  | `revision_eta_range.py` | range of the timescale ratio over the visited regulator range | `eta_range.csv` |
  | `revision_c1_scan.py` | first-order coefficient c1 against control F across promoter architectures (no simulation) | `c1_scan.csv` |
  | `revision_toggle_checks.py spectral_check` | eigenvector residuals and box-size convergence of the metastable toggle rates | `toggle_spectral_check.csv` |
  | `revision_figures.py OUTDIR` | Figure 5 and Supplementary Figure S3 | PDF files in OUTDIR |
  | `make_revision_tables.py OUTDIR` | Supplementary tables of the revision | LaTeX files in OUTDIR |

  Each script's docstring gives its arguments. The `toggle_*` results are split over
  several files, one per run; the runs cover different conditions.

Raw simulation trajectories are not included; they are regenerated by
`benchmarking/suite/run_grid2.py` and `benchmarking/suite/toggle_switching.py`,
which use deterministic seeds.

## Requirements

Python 3.13 with numpy 2.4, scipy 1.17, pandas 2.3, numba 0.67 and matplotlib 3.10
(the versions used for the paper; nearby versions should work).

## Reproducing

Run scripts from `benchmarking/suite/`. Each script states in its docstring which
file in `benchmarking_results/` it writes. The table scripts write LaTeX files into
`../../Supplementary_Material_v2_next_revision/generated/` and
`../../ElsiverFSPromoter_v2_next_revision/generated/`; create these directories, or
change the output paths at the top of each script.
